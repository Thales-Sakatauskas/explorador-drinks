# Explorador de Drinks 🍹

Aplicação web criada com Vue 3 para explorar bebidas usando a API [TheCocktailDB](https://www.thecocktaildb.com/api.php).

## 🚀 Funcionalidades

- ✅ Buscar drinks pelo nome
- ✅ Filtrar por categoria
- ✅ Navegar por drinks via A-Z
- ✅ Ver detalhes com ingredientes e modo de preparo
- ✅ Favoritar drinks (usando Pinia)
- ✅ Layout responsivo (mobile e desktop)
- ✅ Estilo moderno com SCSS e animações

## 🛠 Tecnologias

- [Vue 3](https://vuejs.org/)
- [Vite](https://vitejs.dev/)
- [Pinia](https://pinia.vuejs.org/)
- [Vue Router](https://router.vuejs.org/)
- [Axios](https://axios-http.com/)
- [SCSS](https://sass-lang.com/)

## 📦 Como rodar localmente

```bash

git clone https://github.com/Thales-Sakatauskas/explorador-drinks.git
